# Dependencies

Everything is declared in the single root `pyproject.toml`. There is one
distribution (`kinetic`), one lockfile (`uv.lock`), and one install command.

## Runtime

| Package | Why |
| --- | --- |
| `pyyaml` | Every config and every resolved-config artifact is YAML |
| `requests` | The HTTP client shared by the GDELT and Alpaca adapters. No provider SDK is required |
| `typer` | The `kinetic` CLI |
| `tzdata` | `zoneinfo` needs an IANA database. macOS and Linux usually ship one, but pinning the pure-Python fallback keeps America/New_York session math reproducible in isolated wheel installs and CI runners without system tzdata |

The canonical schemas, storage layer, statistics and event study use the standard
library only — no numpy, scipy or pandas.

## Optional extras

| Extra | Contents | Needed for |
| --- | --- | --- |
| `bigquery` | `google-cloud-bigquery` | The cost-aware GDELT-over-BigQuery path. Imported lazily inside `SafeBigQueryClient`, so importing `kinetic` never requires it or credentials |
| `annotation` | `streamlit` | The local annotation workstation under `tools/annotation` |
| `dev` | pytest, black, ruff, mypy, build, deptry, import-linter, type stubs | Development and validation |

Each extra corresponds to code that actually exists. There are no placeholder
extras.

## Install

```bash
# with uv (recommended — uses uv.lock)
uv sync --all-extras --dev
uv pip install -e .

# or with pip
python -m pip install -e ".[dev]"
```

CI runs `uv sync --frozen --all-extras` followed by `uv pip install -e .`, so a
dependency change that is not reflected in `uv.lock` fails the build.

## Checking

`make deps-check` runs [deptry](https://deptry.com/), which reports dependencies
that are declared but unused, imported but undeclared, or relied on transitively.
It is part of `make validate`.

Do not commit `*.egg-info/`; it is generated by editable installs.
