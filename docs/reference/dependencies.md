# Dependencies

Runtime dependencies are declared **per package** under `packages/*/pyproject.toml` and `apps/*/pyproject.toml`. The root `pyproject.toml` is **workspace-only**: dev tools (pytest, linters) and no bundled library code.

| Distribution (pip name) | Runtime deps | Status |
|-------------------------|-------------|--------|
| `kinetic-common` | PyYAML | implemented |
| `kinetic-pipeline-core` | `kinetic-common` | implemented |
| `kinetic-news-data` | `kinetic-common`, `requests` | implemented |
| `kinetic-market-data` | `kinetic-common`, `requests` | contracts, Alpaca bars, registry, local JSONL store |
| `kinetic-strategy-sdk` | (none) | placeholder |
| `kinetic-trading-platform` | `kinetic-pipeline-core`, `kinetic-news-data`, `kinetic-market-data` | CLI composition root |

**Development:** root `[project.optional-dependencies] dev` — pytest, black, ruff,
mypy, and `types-requests` for HTTP client type checking.

Install from the repo root (see [README](../../README.md)):

```bash
pip install -e ./packages/common \
  -e ./packages/pipeline_core \
  -e ./packages/news_data \
  -e ./packages/market_data \
  -e ./packages/strategy_sdk \
  -e ./apps/trading_platform \
  -e ".[dev]"
```

Do not commit `*.egg-info/`; it is generated by `pip install -e`.

The file `requirements.txt` at the repo root is deprecated; use the `pyproject.toml` files above.

The core financial-data contracts and storage use only the standard library plus
`kinetic-common`. Phase 2 reuses the repository's existing `requests` HTTP approach
for Alpaca historical bars. No Alpaca SDK is required.
